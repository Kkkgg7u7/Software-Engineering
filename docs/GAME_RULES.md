# 当前狼人杀规则与状态机

> 2026-10-30 更新：已支持自由身份配置；原固定组合保留为默认预设。所有身份合计与已入座人数必须等于本局人数。详见 [本次交付记录](CUSTOM_ROLES_AND_ICON_DELIVERY.md)。

版本：2026-10-29。用户确认的细则见 CONFIRMED_GAME_RULES.md；实际校验由原 WerewolfGameEngine 完成。历史长文已保留在 history/GAME_RULES_BEFORE_13.md，不能作为当前玩法依据。

## 配置

4–12 人继续使用原基础牌组与合法狼数；13 人为固定标准局：白狼王 1、普通狼人 3、预言家/女巫/猎人/守卫/白痴/爱神各 1、平民 3。警长不是额外身份牌。13 人房间必须坐满（可包含 AI）；其他房间至少 4 人，非房主真人均准备后可开始。

## 核心规则

| 角色/职务 | 当前行为 |
| --- | --- |
| 狼人/白狼王 | 存活狼人全部投同一合法好人目标才有击杀；分歧或缺票则空刀；每狼每晚只提交一次，先用狼人频道协商 |
| 预言家 | 每夜查一位其他存活者的阵营；查验仅本人可见；查验翻牌确认后完成本阶段 |
| 女巫 | 解药、毒药各一次；解药只作用真实刀口；只允许第一夜自救；同夜双药允许，先毒后救也允许；可主动放弃剩余操作 |
| 守卫 | 可守自己，不可连续两夜守同一人；空守打断连守；单独守护或单独解药免狼刀，同时守护加解药则死亡；毒药不受守护影响 |
| 爱神 | 首夜分两次选择两名不同存活者为情侣（可含自己）；超时由服务器补足合法选择；仅爱神与情侣看到关系；爱神不自动进入情侣阵营 |
| 情侣 | 一人死亡另一人殉情；跨阵营情侣两人独活时赢；跨阵营关系仍存续时不提前用狼人数量优势结束对局 |
| 猎人 | 符合条件的死亡后可开枪或放弃；中毒或殉情不触发；只能由当前死亡技能窗口的本人操作 |
| 白狼王 | 仅被投票放逐后带一名存活玩家或放弃；夜死、殉情、被技能带走均不触发带人 |
| 白痴 | 第一次被投票放逐翻牌免死，此后失去正常投票权；可继续发言，被其他方式杀死或再次放逐可死 |
| 警长 | 第一天天亮选举，存活玩家每人 1 票，可投自己；并列第一重投一次，仍平票则空缺；放逐票为 1.5，其余 1，内部用 3/2 半票单位计数；死亡后移交给存活者或撕毁警徽 |

普通放逐并列最高或全弃票均无人出局，不另开重投。死亡技能依入队顺序处理，包括新死亡、情侣殉情和警徽；技能队列全部处理完才判胜。若没有独立情侣胜利，则狼人全部死亡为好人胜利，狼人达到人数优势为狼人胜利。

## 阶段与权限

WAITING → STARTING → CONFIRM → NIGHT → DAY / SHERIFF_VOTING → DISCUSSION → VOTING → CHECK_WINNER → NIGHT / END。发生死亡技能时插入 DEATH_SKILL 窗口，结束后恢复对应流程。和平夜可直接进入选举或讨论。

前端与 AI 都读取 availableActions 和 selectableTargets，不自行修改身份、药水、票数或胜负。只有当前死亡技能演员允许死后行动；结束后禁止普通游戏动作。夜间行动、情侣关系、查验、药剂状态和未完成演员信息按用户裁剪。

## 超时、重连和重置

身份确认和夜晚超时补默认动作；未投票自动弃票；守卫无操作为空守，爱神补足配对；死亡技能超时放弃，警徽超时撕毁。发言可提前结束，超时跳过；AI 发言结束立即调度下一位。断线后根据当前用户权限重新同步状态；房主退出解散房间。游戏状态仍在单进程内存中，服务器重启不能恢复进行中的对局。

重置回等待阶段会清除上一局角色、情侣、警长、技能与投票状态，再次开局重新发牌。对局结束落库战绩；跨阵营情侣不按原角色阵营重复计胜。

## 验证

Standard13EngineTest 覆盖扩展规则与隐私；Standard13RuntimeTest 用 12 种种子走真实房间完整对局，并覆盖夜晚超时不会跳过死亡技能窗口。GamePlatformIntegrationTest 覆盖房间满员、12 AI、13 牌组元数据与伪造技能拒绝。实际浏览器验证到首轮警长选举/重投及桌面、手机布局。
