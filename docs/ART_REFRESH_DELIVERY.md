# 狼人杀美术更新与验收

基于用户提供的参考截图，使用内置 imagegen 分别生成角色及场景插画，保留截图的扁平卡通、蓝紫夜色、简洁几何纹样和轻松桌游氛围。图片经过 JPEG 编码优化，分辨率保持原样；中文卡名由 SVG 绘制，确保用字准确清晰。每张完整卡牌为独立 SVG，包含自己的图像和名称，浏览器使用时不依赖跨文件图像加载。

## 素材及目录

- `frontend/public/assets/art/roles/`：20 张 1024×1536 角色插画的压缩副本。
- `frontend/public/assets/roles/*-card.svg`：20 张带中文名称的完整卡牌。现有九种身份的 `*-icon.svg`、`*-token.svg` 也更新为同风格缩略图；`hidden-back.svg` 为新卡背。
- `frontend/public/assets/art/scenes/`：`preparation.jpg`、`game.jpg`、`night.jpg`、`day.jpg`、`result.jpg`，用于准备、桌面、夜晚、白天和结算。
- `frontend/public/assets/art/card-back.jpg`：生成的卡背插画；`frontend/public/assets/art/preview.html` 提供 20 张卡及场景预览，清楚区分可用身份与预留素材。
- 角色插画与五张背景图共约 4.1 MB；页面使用的 SVG 内嵌压缩图，避免 SVG 外部图片加载限制。

已经实现的九种身份：村民、预言家、女巫、猎人、守卫、爱神、白痴、狼人、白狼王。

已生成但尚未实现游戏规则的十一种身份：通灵师、长老、炸弹师、织梦人、白夜使者、月夜祭司、老酒鬼、小绵羊、企鹅、熊、大公鸡。素材预留不等于这些身份已经可以加入对局。

## 接入范围

准备页身份配置、身份翻牌与确认、座位结算身份图、战绩角色图鉴、游戏目录封面、发牌及行动特效、卡背、牌桌、夜晚/白天背景及结算面板均接入新素材。身份信息仍由服务端授权投影控制，素材资源不改变发牌和规则。按钮继续使用现有组件；上次用户指定的应用图标保留。

相关代码文件：`RoleCard.vue`、`RoleCountsEditor.vue`、`PlayerSeat.vue`、`SeerRevealOverlay.vue`、`EffectManager.vue`、`PhaseTimer.vue`、`RoomView.vue`、`GameView.vue`、`RecordsView.vue`、`GameController.java`、`WerewolfDefinition.java`、`RoleType.java`。现有身份显示名“平民”统一为“村民”，阵营与胜负规则不变。替换路径追加版本参数，避免浏览器继续显示旧图。

## 验收范围

- 前端类型检查和生产构建通过；后端 20 类、152 项回归测试全部通过。
- 程序检查 20 张卡的 SVG、中文名称、嵌入图及 1024×1536 尺寸，九种身份各自图标/头像和卡背；五张背景均正常解码。HTTP 测试 44 个实际资源路径和服务端元数据引用均可访问。
- 隔离服务中浏览器实际完成建房、添加 AI、发牌、卡牌翻面、夜晚、白天、投票、结算及再开一局；检查好人蓝卡、狼人红卡、中文角色名和结算身份显示。
- 320 与 390 像素视口检查图片与文字显示；针对 320 像素修复倒计时横向溢出，八人对局使用移动端网格并验证座位互不重叠；浏览器错误日志为空。
- 保留用户当前 18080 服务，新的预览/验收服务使用隔离的本地端口 18081，测试数据库与用户数据隔离。验收不代表公网部署或跨设备网络验证。

## 生图提示词组

使用内置 imagegen，以用户截图作风格参考，并以生成的村民卡作为系列构图样例：原创、扁平二维卡通、清晰几何轮廓、蓝紫夜色、月亮星星、统一装饰边框、竖版完整角色、底部预留卡名区域；狼人和白狼王使用暗红卡面。每个角色单独描述其职业特征。五张场景分别描述月夜准备区、俯视桌游牌桌、夜村、黎明讨论区和结算夜景，保持低对比以承托前景文字；卡背使用月亮与神秘纹样。
