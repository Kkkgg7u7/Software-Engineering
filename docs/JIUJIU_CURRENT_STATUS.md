## 当前边界

- 只有狼人杀是可游玩游戏。GameRegistry 统一元信息/配置校验/实例创建，RoomManager 按 gameType 分派；已有 RoomRuntime 仍是狼人杀运行时，保留原接口以兼容当前客户端。新增第二种游戏仍需要独立运行时及协议适配，不能把目录注册声称为完全通用引擎。
- 单实例内存保存进行中的房间/对局。账号、社交、动态、图片、战绩持久化；重启会结束当前房间，不具备跨进程续局或多实例共享调度。
- 模型已通过本地 HTTP 模拟服务验证有效响应、非法动作、超时、异步和预算；没有使用真实 Provider Key，也没有产生外部付费模型调用。
- 公网部署需要真实服务器、域名、有效 TLS 证书、数据库与 STUN/TURN 配置。目前未发布公网服务，未验证 Docker/MySQL、真实麦克风双设备音质、TURN 中继或 13 人语音容量。
- 本地语音测试使用合成音轨，不申请用户麦克风权限。真实麦克风由用户点击加入语音并自行授权。
