# 阶段 5：游戏大厅、配置匹配与邀请

完成游戏目录 API 和狼人杀展示页，统一房间 gameType / configuration 元数据、邀请和局内私聊开关。匹配按游戏、人数、狼人数、私聊配置筛选公开无密码、无 AI 等待房；优先人数多、等待久的房间，无候选时创建对应配置房。

好友和群聊支持真实 GAME_INVITE 消息卡片，点击后显式加入房间。服务器检查发送者房间成员身份、等待状态、邀请开关及目标会话权限。密码房仍须验证密码，邀请不提供密码或越权入房能力。修改、准备、退出、踢人接口验证 URL 房间码与当前成员关系。局内私聊开关由服务器执行。

验证：14 个测试类、104 项测试通过；前端类型检查与构建通过。真实 HTTP 回归验证 8 人配置匹配、邀请权限与重启后的墙内容持久化。本轮重新登录后，浏览器选择 6 人匹配，结果为实际 6 个座位，未再复现先前人数异常。邀请卡片已在聊天界面验证。

当前边界：目录注册与配置校验已有 GameDefinition / GameRegistry 接口；房间运行时仍使用现有狼人杀引擎，完整多游戏运行适配将在集成阶段继续处理。当前未添加虚假的第二款可用游戏。13 人玩法与语音不计入本阶段交付。

数据库：V006 增加 game_type、allow_invites、private_chat_enabled。H2 启动自动升级；已有 MySQL 应手动执行同名迁移。未访问原 backend/data 数据库，运行验证使用工作区独立 H2 文件。
